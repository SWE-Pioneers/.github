# Software Engineering Pioneers

> **We don't code software. We pioneer it.**

Software Engineering Pioneers (**SWE Pioneers**) is a software engineering and managed infrastructure firm based in Tripoli, Libya, serving organizations across Libya and MENA. We engineer custom business software from requirements and architecture to production, and we operate hardened ERP, business email, and cloud infrastructure with full documentation and zero vendor lock-in.

> *"We don't just write code. We engineer, deliver, and support systems intended to create business value."*

## Engineering Principles

- **Architecture Before Code** — Every system is sized to actual operational requirements, avoiding both fragile shortcuts and unnecessary complexity.
- **Zero Vendor Lock-In** — Clients receive complete technical documentation and operational runbooks so they retain full ownership of their code, servers, and data.
- **Accountable Delivery** — Structured sprint reviews, live demonstrations, measurable SLAs, and contractual post-delivery warranty.
- **Open-Source Foundation** — Built on and contributed back to battle-tested open-source platforms rather than reinventing core infrastructure.

## Flagship Platforms (Proprietary)

In addition to client engineering, we build and operate our own internal platforms:

- **Overcast Cloud Portal** — Self-service client hosting and control platform (Django-Bolt API, React SPA, and std-only Rust console broker) supporting instant demos, managed Frappe/ERPNext, PostgreSQL, MinIO S3, self-serve business email, and local billing.
- **SWE-Pipeline** — Custom CI/CD orchestrator engine written in std-only Rust and a Frappe/ERPNext container image factory with health-gated, zero-downtime rollouts.
- **Managed Client VPS & Mail Platform** — Per-client isolated VPS architecture combining Django-Bolt (SSR + API), full Mailu email stack, zero-SSH Ansible onboarding, host security hardening, and S3 backup automation.
